Recommendation
Go with A — Split ₹
It's the only concept that immediately tells you: this is for money, this is Indian, and it involves splitting. The teal/red duality reinforces the app's core semantic — green for "owed to you", red for "you owe" — so the icon becomes part of the product language, not just a shell.

For Android — use A with a solid #0D0D0D background layer and the ₹ as the foreground layer for adaptive icons.
For iOS — exactly as shown, the rounded corners are applied by the OS.
ASO edge — no competitor in the expense/splitting category uses ₹ as their icon mark. This is ownable.
